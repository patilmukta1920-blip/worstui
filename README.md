# 💩 Worst UI Word Search Website 🪳

> **"Official Ultra Super Word Search Pro 2000 Ultimate Gold Edition"**

A deliberately cursed, retro-chaotic, bad-UI-battles masterpiece created with pure HTML5, CSS3, and Vanilla JavaScript.

## 🌟 Horrific Features

- 🎨 **Dark Sludge Palette**: Muddy brown, rotten pea green, greasy mustard, and eye-searing neon magenta & cyan.
- 🔤 **Inverted Typography**:
  - The main `<h1>` title is **microscopic (6px tall)**.
  - The footer copyright disclaimer is **gargantuan (42px giant bold text)**.
- 📐 **Zero Alignment & Spastic Spacing**: Asymmetric borders, negative margins, rotated containers, and wavy decorations.
- 🔍 **Interactive Word Search**:
  - 10×10 grid of chaotic letters with randomized font sizes and rotations.
  - Search words: `CHAOS`, `UGLY`, `PAIN`, `EMOJI`, `POPUP`, `SLUDGE`, `VOMIT`, `CLOWN`.
  - Violently jiggling word input box and bloated search button.
  - 📉 Negative scoring system (you lose 1,000 points whenever you find a word!).
- 🚨 **Unwanted Popups & Annoyances**:
  - 🍪 **9,418 Cookie Modal**: The "Decline" button physically dodges and runs away from your cursor.
  - 🚨 **Word Alert Level Red**: Intercepts word searches with absurd accusations.
  - 🍞 **Moldy Toast Assistant**: A parody of Clippy dispensing sarcastic, unhelpful tips.
  - ☣️ **"ACTIVATE WORSE MODE"**: Inverts colors and shakes the viewport.
  - 🔊 Built-in Web Audio API synthesizer generating crunchy 8-bit sound effects.
